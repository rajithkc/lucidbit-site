# Subscription Calendar product page

Uses the shared LucidBit layout and navigation. Publish through the repository’s GitHub Pages workflow.

## Screenshots

The iPhone gallery contains six actual app screenshots with signature-green marketing artwork. It scrolls automatically, pauses on hover or keyboard focus, and respects reduced motion.

The six Mac feature rows use actual dark-mode app captures in `assets/screenshots/macos/`, without marketing artwork embedded in the images. Shared rounded corners and shadows match the other app pages.

## Pricing and links

Essential includes five active subscriptions and one completed import. Lifetime Pro upgrades are sold separately for iOS and Mac. US prices:

| Platform | Single | Family (up to 6 people) |
| --- | --- | --- |
| iOS / iPadOS | $7.99 | $9.99 |
| macOS | $11.99 | $14.99 |

Apple handles local pricing. Only Family purchases include Family Sharing.

Store buttons use the app record supplied by the owner: https://apps.apple.com/app/id6806599466. The links are intentionally enabled before the listing becomes public.

The changelog documents version 1.0, the initial iOS and macOS release.
