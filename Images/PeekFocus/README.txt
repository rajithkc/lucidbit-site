Drop your PeekFocus icon PNG here as:

    Icon-macOS-Default-1024x1024@1x.png

(Match the naming convention used by ActiveStat and GentleLimit folders.)

Once the file is in place, peekfocus.html will pick it up automatically —
no code changes needed. Until then the page renders a CSS placeholder
glyph in the same spot.

Additional asset slots the page expects (all optional, placeholders
render if missing):

  • Icon-macOS-Default-1024x1024@1x.png   — App icon
  • Hero.png                               — Composite hero visual (optional, replaces CSS mock)
  • Timer.png                              — Feature image: timer presets
  • Sessions.png                           — Feature image: session log
  • MenuBar.png                            — Feature image: menu-bar integration
  • Settings.png                           — Feature image: preferences
  • peekfocus_preview.mp4                  — Optional looping hero video
