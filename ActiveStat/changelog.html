1.1 March 2026

Telemetry Refinement Update. This version introduces deeper hardware awareness and UI customisation:

  • Apple Silicon Clusters: Added independent tracking for Performance and Efficiency core clusters to better visualize M-series load distribution.
  • Memory & Swap Clarity: Introduced dedicated monitoring for SSD Swap Read/Write speeds and improved breakdowns for App, Wired, and Compressed memory.
  • Expanded Battery Health: Now tracks real-time Battery Temperature and Charge Cycles.
  • Storage Telemetry: Added live disk throughput (Read/Write) tracking for internal and removable volumes.
  • User Personalization: Introduced "Smart Auto-Expand" rows, Insight Verbosity levels, and granular thresholds for storage and battery alerts.
  • Stability: Refined the Sustained Load Engine to further reduce UI noise during transient system spikes.
